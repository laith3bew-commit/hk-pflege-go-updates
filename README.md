# HK Pflege Go: Updates

Hier liegen nur die Versionsangaben für die Android-App HK Pflege Go des Ambulanten Pflegedienstes Heike Kühn.

- `version.json`: aktuelle Version, Download-Adresse und SHA-256-Prüfsumme.
- Die Installationsdatei (APK) hängt an den Releases.

Die App prüft diese Datei selbst und zeigt „Neue Version verfügbar“. Vor jedem Update werden die Daten gesichert.

In diesem Repository liegen keine Daten von Mitarbeitern oder Klienten, keine Passwörter und keine Schlüssel.
